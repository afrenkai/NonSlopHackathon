The bundled typefaces are licensed under the SIL Open Font License 1.1; each upstream license and copyright notice is included alongside its font. The Fontsource assets use package version 5.3.0. Outfit is served locally from the Google Fonts v15 WOFF2 files.

| `ibm-plex-mono.woff2` | `@fontsource/ibm-plex-mono` | Latin, 400, normal |

| `outfit-latin-ext.woff2` | Google Fonts Outfit | Extended Latin, variable weight 100–900, normal |
