# Locally served typefaces

The field guide uses the Latin WOFF2 subsets from these Fontsource npm packages, version 5.3.0. All four typefaces are licensed under the SIL Open Font License 1.1; each upstream license and copyright notice is included alongside its font.

| Asset | Source package | Subset |
| --- | --- | --- |
| `fraunces.woff2` | `@fontsource-variable/fraunces` | Latin, variable weight, normal |
| `schibsted-grotesk.woff2` | `@fontsource-variable/schibsted-grotesk` | Latin, variable weight, normal |
| `nanum-pen-script.woff2` | `@fontsource/nanum-pen-script` | Latin, 400, normal |
| `ibm-plex-mono.woff2` | `@fontsource/ibm-plex-mono` | Latin, 400, normal |
